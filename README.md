# 포코노트 - 음악 레슨 에이전트

레슨 중에는 학생을 보고, 연주를 듣고, 다음 과제를 생각해야 합니다. 메모까지 하다 보면 수업의 흐름이 끊기기 쉽습니다.

포코노트 레슨 에이전트는 선생님이 레슨을 녹음해 두면, 수업이 끝난 뒤 음성에서 실제로 언급된 내용을 골라 레슨 일지 초안으로 정리해 주는 데모입니다. 선생님이 내용을 확인하고 수정한 뒤 승인하는 흐름까지 한 화면에서 볼 수 있습니다.

이 저장소는 NVIDIA 해커톤을 위한 독립 실행 데모입니다. 포코노트 본 서비스의 로그인, 학생 관리, 결제, 운영 데이터베이스까지 포함한 제품 전체를 옮겨 둔 저장소는 아닙니다.

## 핵심 시나리오

데모는 레슨 기록 화면에서 시작합니다.

1. `레슨 AI로 요약하기`를 누릅니다.
2. 녹음을 시작하고 레슨이 끝나면 종료합니다.
3. AI가 만든 레슨 일지 초안을 확인합니다.
4. 요약, 곡·구간, 잘된 점, 개선할 점, 다음 연습 과제를 직접 수정할 수 있습니다.
5. 필요하면 `음성 보정 후 다시 분석`을 실행합니다.
6. 내용을 확인하고 저장하면 해당 회차의 레슨 기록으로 돌아갑니다.

현재 기본 실행 모드는 서버 없이 동작하는 데모 모드입니다. 따라서 이 저장소만 받아도 전체 화면 흐름을 바로 시연할 수 있습니다.

## 해커톤 심사의 주요 항목

- 실제 문제 해결: 레슨 중 메모 부담을 줄이고, 수업이 끝난 뒤 바로 검토할 수 있는 기록을 만듭니다.
- 에이전트 흐름: 녹음, 전사, 내용 정리, 이전 레슨 비교, 초안 수정, 승인까지 한 흐름으로 연결합니다.
- NVIDIA 기술 활용: Speech NIM은 음성 전사에, Nemotron 계열 모델은 레슨 일지 구조화에 사용할 수 있도록 연결 지점을 마련했습니다.
- 안전성과 신뢰성: API 키를 브라우저에 두지 않고, 원본 음성은 임시로만 다루며, 최종 결과는 선생님이 승인합니다.
- 근거 기반 결과: 녹음에서 확인되지 않은 내용은 임의로 채우지 않습니다.
- 사용자 경험: 실제 레슨 기록 화면에서 시작해 별도의 복잡한 설정 없이 기능을 확인할 수 있습니다.

## 주요 설계 원칙

### 녹음보다 중요한 건 검토 과정

AI가 만든 내용을 곧바로 학생 기록으로 확정하지 않습니다. 초안 상태에서 선생님이 내용을 확인하고 고친 다음에야 레슨 기록으로 반영합니다.

### 들은 내용만 기록하기

음성에서 확인되지 않은 곡명, 구간, 강점, 과제는 임의로 채우지 않는 것을 전제로 합니다. 이전 레슨과의 비교도 실제로 전달된 이전 기록이 있을 때만 보여 줍니다.

### 원본 음성은 오래 보관하지 않기

재분석에 필요한 동안에만 브라우저 메모리에 원본 음성을 임시로 둡니다. `localStorage`나 장기 저장소에는 저장하지 않습니다. 실제 서비스로 연결할 때는 보존 기간과 삭제 정책을 서버에서도 함께 관리해야 합니다.

## 실행 방법

Node.js가 설치되어 있다면 저장소 루트에서 정적 서버를 실행합니다.

```bash
npx -y serve . -l 4173
```

브라우저에서 다음 주소를 엽니다.

```text
http://localhost:4173/poconote-app.html#/students/doyoon/lessons/record/8
```

별도의 마이크 권한, NVIDIA 계정, API 키, GPU 서버 없이 다음 흐름을 재현할 수 있습니다.

```text
레슨 기록 → AI 요약 시작 → 녹음 종료 → 샘플 전사·분석 → 초안 수정 → 저장
```

## NVIDIA 연결 구조

현재 폴더에서 바로 실행되는 것은 데모 모드입니다. 실제 NVIDIA 서버를 붙일 수 있도록 음성 전사, 레슨 분석, 저장 기능을 연결하는 지점은 코드에 따로 나누어 두었습니다.

```text
첫 분석
브라우저 녹음
  → Speech NIM으로 음성 전사
  → Nemotron 계열 모델로 레슨 일지 정리

재분석을 선택한 경우
임시 음성
  → Maxine/BNR 호환 음성 보정
  → Speech NIM 재전사
  → Nemotron 재분석
```

브라우저에 NVIDIA API 키를 넣는 방식은 사용하지 않습니다. 실제 연결에서는 브라우저가 서비스 서버의 API만 호출하고, 서버 또는 보안 게이트웨이가 Speech NIM과 Nemotron 엔드포인트를 호출해야 합니다.

이 프로젝트에는 다음 연결 지점이 준비되어 있습니다.

- Speech NIM 전사 연결
- Nemotron 호환 분석 연결
- 재분석 때만 사용하는 음성 보정 연결
- 승인된 레슨 일지를 보낼 수 있는 저장 연결

실제 GPU 서버, 운영용 API, OpenShell/NemoClaw 정책 파일은 포함하지 않았습니다.

## 레슨 일지에 담기는 내용

- 수업 전체 요약
- 곡과 레슨에서 언급된 구간
- 잘된 점
- 개선할 점
- 지난 레슨 이후의 변화
- 반복해서 나타난 이슈
- 다음 연습 과제
- 다음 레슨에서 확인할 항목

모델 요청에는 학생 이름 대신 불투명한 학생 식별자와 날짜, 필요한 이전 레슨 문맥만 전달하는 구조를 사용합니다. Nemotron에는 원본 음성을 직접 보내지 않고, 음성 전사 결과를 전달합니다.

## 프로젝트 구성

```text
.
├── poconote-app.html       # 브라우저에서 여는 데모 화면
├── assets/                 # 화면에 사용하는 캐릭터와 폰트
├── spa/                    # 레슨 기록과 AI 요약 화면을 구성하는 코드
├── tests/                  # 데모 범위를 검사하는 테스트
├── README.md
└── .gitignore
```

`spa`는 여러 화면을 한 페이지 안에서 빠르게 전환하기 위한 코드 모음입니다. 이 프로젝트에서는 레슨 기록 화면과 레슨 AI 화면만 들어 있습니다. 포코노트 본 서비스의 다른 화면을 복사해 둔 것이 아닙니다.

## 구현 범위

- 레슨 기록 화면과 레슨 AI 화면
- 서버 없이 실행되는 전체 데모 흐름
- 녹음 시작·중지·종료와 분석 상태 표시
- 구조화된 레슨 일지 초안
- 이전 레슨 비교
- 초안 수정과 저장 확인
- 음성 보정 후 재분석 흐름
- 데모에 필요한 캐릭터와 서비스 폰트

## 향후 서비스 연동 범위

- 로그인과 선생님·스튜디오 권한 확인
- 실제 학생 식별자 조회와 접근 제어
- 승인된 레슨 일지의 운영 데이터베이스 저장
- 음성 보존 기간, 삭제, 감사 기록
- 브라우저 종료 후 미완성 녹음 복구
- Speech NIM, VAD, Maxine/BNR의 실제 GPU 품질 검증
- 여러 선생님과 조직을 위한 권한 관리

따라서 이 프로젝트는 포코노트에 붙일 수 있는 레슨 에이전트의 해커톤 프로토타입입니다. 포코노트 본 서비스의 백엔드까지 완성된 저장소는 아닙니다.

## 검증

독립 데모의 범위 테스트와 JavaScript 문법 검사는 다음 명령으로 실행할 수 있습니다.

```bash
node --test tests/hackathon-scope.test.cjs
for file in spa/*.js spa/views/*.js; do node --check "$file"; done
```

현재 테스트는 메인 서비스의 다른 화면과 자산이 해커톤 데모에 다시 섞이지 않았는지 확인합니다. 실제 Speech NIM, Nemotron, GPU 음성 보정 서버와 운영 데이터베이스를 호출하는 통합 테스트는 별도 서버가 없으므로 포함하지 않았습니다.

## 유의 사항

- 실제 API 키, 학생 개인정보, 개인 음성은 저장소에 넣지 않습니다.
- 데모 모드만으로도 화면 시연이 가능합니다.
- NVIDIA 연결 모드는 별도 서버와 GPU 엔드포인트를 추가한 뒤 검증해야 합니다.
